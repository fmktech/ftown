# Session preview contract — FROZEN v1 (P1/P2/P3 reviewed)

## Product and trust boundary
One self-contained UTF-8 .html/.htm file per existing session, maximum1,048,576 bytes; inline CSS/JS and data images. No sibling/external assets, fetch backend, file URLs, module asset server or feedback channel. Registration is explicit local-CLI control authority; browser read is existing encrypted read authority. Same-UID OS users/agents are trusted registrants (already can read host files); malicious privileged filesystem races outside threat boundary. Never claim sandbox is a blanket network/CPU isolation boundary: iframe self-navigation and arbitrary JS CPU remain browser limitations. No new public endpoint, bearer URL, credentials or broad permissions.

## Encrypted browser protocol
Shared type-only/constant contract bridge/src/preview-protocol.ts consumed from UI via existing cross-package import pattern. Commands `session_preview_status`, `session_preview_chunk` are read permission; required valid sessionId, previewId UUID, bridgeId existingrouting. No remote paths. Every variant includes literal state. Missing session RPC uses success:false/data.code=not_found/genericerror rather than pretending HTTPstatus. Extend controllerresult with too_large mapped413; existing invalid maps400. Status request{bridgeId,sessionId,previewId,knownRevision?}; revision is lowercase SHA256 hex64 of exactbytes. Status response discriminated state:
- ready {previewId,revision,totalBytes}
- unchanged {previewId,revision,totalBytes}
- unavailable {previewId,reason:'missing'|'too_large'|'invalid_utf8'|'invalid_file'|'unavailable'}
- unregistered {state:'unregistered'} (includes id mismatch/clear/missingregistration; missing session ordinary404/notfound wrapper)
Chunk request{bridgeId,sessionId,previewId,revision,offset}; offset integer>=0, multiple98,304 and <totalBytes, zero allowed emptyfile specialcase returnsdataempty done true. Response state chunk {previewId,revision,totalBytes,offset,dataBase64,done}; state stale_revision (includes changedbytes/register/clear/delete) or unavailable with reasons above. Controller methods getPreviewStatus(sessionId,previewId,knownRevision?) and getPreviewChunk(sessionId,previewId,revision,offset) return protocolunions; setPreview/clearPreview mutate serializedmetadata.
Reads bounded fullfile with descriptor regular-file and sizecheck before allocation, fatal UTF8validation, SHA256. Status unchanged compares actualbytes notonlymtime; chunk revalidates currentregistration, file anddigest on eachrequest before slice<=98,304 rawbytes. No unbounded snapshots/cache/timers. One boundedread per request, max4 concurrent file reads perbridge; reject busy as unavailable reason unavailable, no waiting queue. Limit storedsource/path UTF-8 byte lengths4096. Reject symlink components belowcanonicalroot, symlinkroot and final symlink, nonregularfiles, dotdot escape/crossroot; canonicalroot/pointer match sessioncurrentworkingDir. Use descriptorreading + nofollowfinal; recheck registration after asynchronousread so clear/register/remove cannot release oldbytes. No claim hostile rename races fullyprevented. Generic errors contain no paths. Serialized response must stay under300,000bytes and encryptedlimit450,000bytes; chunk sizes selected with doublebase64 margin.
