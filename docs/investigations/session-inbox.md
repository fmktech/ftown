# Session Inbox — implementation contract and ownership

Outcome: replace the truncated Needs attention section with a persistent Inbox button pinned above the Bridges header outside the sidebar scroll region. Show an outstanding-message count (not read tracking); icon plus count in collapsed sidebar. Clicking opens a modal Inbox listing full plain-text notices, session/bridge names and timestamps, newest first. Opening does not dismiss. Empty copy: No messages. Each entry has Open session, Dismiss and a multiline Reply composer. Send reply queues durable mail to that exact session; success says Reply queued. Do not claim the agent read it, auto-dismiss notices, inject terminal keys or execute shell commands. Keep the composer draft on failure and show actionable errors. No automatic retry after uncertain send. All UI uses existing colors/typography, 44px actions, 320px responsive layout, scrollable modal, Escape and Close with focus restoration. No horizontal overflow. Hidden session/bridge filtering and existing authority filters are retained. A new notice replaces the active notice for that session as today; this is not a full historical archive.
