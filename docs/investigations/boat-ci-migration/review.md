## Full-history finding — repaired and closed

### R5 — Preserve remote-only refs when restoring full history (P1)

Trace: `scripts/ci/boat-runner.mjs`, `prepare()` creates a bundle with `--all HEAD`; `upload()` restores it with ordinary `git clone /home/user/history.bundle /home/user/repo` before the detached checkout. The original history workflows use `actions/checkout` with `fetch-depth: 0`, whose fetched branch tips reside under `refs/remotes/origin/*`. Ordinary clone imports branch heads/tags rather than preserving all source ref namespaces. Commits reachable only through an unmerged remote-tracking branch can therefore remain as objects in the bundle but lose all refs in the restored repository. [Git's clone documentation](https://git-scm.com/docs/git-clone) distinguishes ordinary branch cloning from all-ref mirror behavior.

This changes the existing security scan's coverage: Gitleaks 8.30.1 defaults to `git log` with `--full-history --all`, so losing a remote-only ref removes that branch's unique commits from the scan. [Pinned Gitleaks source](https://raw.githubusercontent.com/gitleaks/gitleaks/v8.30.1/sources/git.go)

Bounded fix: initialize the target repository and explicitly fetch all bundle refs with `+refs/*:refs/*`, plus the bundle's `HEAD`, then check out and verify the exact source revision. Do not retain a configured remote or authenticated URL. For bridge-version, also verify the exact base/head objects. Add an isolated Git fixture containing an unmerged commit reachable only through a remote-tracking ref; the restored ref/SHA and its reachability through `git rev-list --all` must match the source. Root owns actual provider execution of the repaired transfer path.

The final repair implements those properties through `historyRestoreScript()` and an isolated Git fixture. It also handles the current-branch import edge: a fresh `git init` leaves its configured default branch current, which can match a bundled local branch; Git normally refuses that update. The disposable import explicitly permits the update, and its fixture forces both source and target default branches to `main`. The fixture verifies detached exact SHA, preserved remote-only ref/reachability, missing-object failure, and absent configured remotes. Source closure accepted. [Git fetch's current-branch protection](https://git-scm.com/docs/git-fetch)
