## R2 scoped delivery semantics
Running check is admission to existing inbox handoff, not an atomic guarantee against a process stopping during asynchronous delivery. A handoff admitted while running can finish after stop; no automatic start/resurrection and no exactly-once end-to-end delivery claim. Already-stopped admission retains unread mail. Do not broaden existing process stop/ordinary mail transaction semantics; document scope where stopped queue behavior is described.
